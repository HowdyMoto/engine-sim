Start the simulator

Audio is synthesised from the simulated exhaust pressure waves, so the browser needs a click before it will let sound play.

Then press A for ignition and hold S to crank. Some engines need a little throttle (W) to catch, and the big ones take a few seconds to spin up.

Key & controller bindings

Every action takes a keyboard key and a controller input, and either one drives it. Click Bind, then press the key, pedal, paddle or button you want. Pedal calibration follows the movement, so any rest position or travel direction works, and it keeps refining as you drive.

Browser storage is unavailable, so these bindings will be lost when the page closes.

Custom engine

Describe an engine as JSON — layout, geometry, firing order, cams, flow. Crank phasing is derived from the firing order. Unset fields get sensible defaults.
